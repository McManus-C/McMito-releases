# MCMITO — NIRS muscle mitochondrial oxidative capacity

**Website: https://mcmito.com/**

MCMITO is a Windows desktop application that turns repeated-cuff near-infrared spectroscopy (NIRS)
recordings into reproducible measures of skeletal-muscle mitochondrial oxidative capacity: automated
occlusion detection, transparent per-occlusion slope extraction (mV̇O₂), mono-exponential recovery-curve
fitting to the rate constant *k* and time constant *τ*, exercise-phase metrics, and publication-ready
Excel and PDF exports.

This repository hosts the **official installers and signed update manifests** used by MCMITO's
built-in updater (Settings → About → *Check for updates*). The source code is not published here.

## Download

Get the latest installer from the [Releases](../../releases/latest) page. MCMITO is currently
**free of charge** for research and educational use under a machine-bound, time-limited licence —
request a licence key through https://mcmito.com/.

MCMITO runs entirely on your own computer; your recordings never leave your machine.

used for diagnosis, monitoring, or clinical decision-making.
